# PawMap

Proyek Flutter Android untuk tugas Teknologi Berkembang Kelompok 4. PawMap dirancang untuk mencatat penampakan kucing dan menampilkan riwayat lokasi serta waktu penampakannya dalam satu profil.

## Menjalankan proyek

Gunakan Flutter 3.38.5 dengan Dart 3.10.4, Android SDK, dan emulator atau perangkat Android yang terhubung.

```sh
flutter pub get
flutter run
```

Titik masuk aplikasi ada di `lib/main.dart`. Commit awal menyiapkan proyek Android dan layar pembuka sederhana yang menampilkan nama PawMap.
